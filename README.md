## AI-Augmented Development 🤖

I treat AI as a production-grade tool, not autocomplete. This workflow wasn't built from tutorials. It comes from heavy daily usage of [Claude Code](https://www.anthropic.com/claude-code) and constant experimentation, figuring out what actually delivers high-quality, safe, and maintainable code under real project constraints.

<table>
  <tr>
    <td width="30%">🛠️ <strong>Claude Code as a pair</strong></td>
    <td>Agentic loops for refactors, test scaffolding, codebase-wide migrations. Supervised, reviewed, never blind-merged</td>
  </tr>
  <tr>
    <td>📜 <strong>Custom <code>SKILL.md</code> authoring</strong></td>
    <td>Project-specific skills that encode conventions, design tokens, and API contracts, so AI output matches the codebase, not just training data</td>
  </tr>
  <tr>
    <td>📐 <strong>Spec to code pipelines</strong></td>
    <td>Figma frames and design tokens converted into typed components with stories and tests. Auditable diffs, not "vibe-coded" output</td>
  </tr>
  <tr>
    <td>🧪 <strong>AI-assisted QA</strong></td>
    <td>Generated test scaffolding, a11y audits and copy/i18n review caught before reviewers' time is spent</td>
  </tr>
  <tr>
    <td>🚦 <strong>Guardrails first</strong></td>
    <td><code>CLAUDE.md</code> project conventions, strict typing, lint/typecheck gates, human-owned code review. AI scales me, it doesn't replace judgment</td>
  </tr>
</table>

> **The point:** I ship faster *and* keep the bar high. Every AI-generated line goes through the same review, typing, and CI gates as anything I write by hand.
